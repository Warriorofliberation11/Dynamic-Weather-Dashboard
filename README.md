# 🌦️ Dynamic Weather Dashboard

A responsive web application that displays real-time weather information using the OpenWeatherMap API.  
Users can search weather by city name or use their current location and view a 5-day forecast.

This project is built using HTML, CSS, and JavaScript.

---

## 🚀 Features

✅ Search weather by city name  
✅ Get weather using current location (Geolocation API)  
✅ Real-time temperature, humidity, and wind speed  
✅ Weather condition icons  
✅ 5-day forecast display  
✅ Responsive UI design  
✅ Error handling for invalid city or network issues  

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeatherMap API
- Geolocation API

---

## 📸 How It Works

1. User enters a city name or allows location access.
2. Application fetches real-time weather data from API.
3. Weather details and forecast are displayed dynamically.
